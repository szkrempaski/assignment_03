This assignment taught me that Streamlit's rerun model changes how you have to
think about state entirely. My first version of process_files.py reset its
counter to zero on every rerun because I treated it like a normal Python
variable, and I only fixed it once I understood that anything meant to
survive a rerun has to live in st.session_state and get initialized just once,
not every time the script runs top to bottom. The trickier bug was realizing
that st.file_uploader keeps returning the same file on every rerun, so I had
to gate the actual processing behind a button click instead of just checking
whether a file was present. Going forward, I'd like more practice with more
complex session state, like letting a user edit or remove a past entry
instead of just appending to a list, since that's where I'm least confident
I'd get the guard logic right on the first try.
